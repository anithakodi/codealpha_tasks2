# codealpha_tasks2
📌 Description:
This project is a responsive Image Gallery built using HTML, CSS, and JavaScript. It allows users to view images in a clean layout with smooth transitions and lightbox functionality.

🚀 Features:

Responsive design for mobile and desktop
Lightbox view for image preview
Next/Previous navigation buttons
Smooth hover effects and transitions
Clean and modern UI

🛠️ Technologies Used:

HTML
CSS
JavaScript

🎯 Purpose:
This project was developed as part of the CodeAlpha Internship to enhance frontend development and UI design skills.
